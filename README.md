# 📧 SMS & Email Spam Classifier

A Machine Learning based web application that classifies SMS and Email messages as **Spam** or **Not Spam (Ham)**.

## 🚀 Project Overview

This project uses Natural Language Processing (NLP) and Machine Learning techniques to analyze text messages and predict whether a message is spam or legitimate.

The model processes the input text, converts it into numerical features using **TF-IDF Vectorization**, and then predicts the category using a Machine Learning classifier.

## 🛠️ Technologies Used

- Pandas
- NumPy
- Scikit-learn
- NLTK
- TF-IDF Vectorization
- Machine Learning
- Streamlit

8. Streamlit Web App Development

## ✨ Features

- Enter any SMS or Email message
- Predict whether the message is **Spam** or **Not Spam**
- Simple and user-friendly interface
- NLP-based text preprocessing
- Machine Learning based prediction
